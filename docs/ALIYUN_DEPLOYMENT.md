# 阿里云部署清单

## 现在不需要提供的内容

- 阿里云主账号密码
- 主账号 AccessKey
- RAM 用户长期 AccessKey
- OSS 公共读写权限
- 任何银行卡、身份证或真实访问密码

这些内容不应通过聊天、Git 或前端代码传递。

## 正式部署目标

```text
同一 HTTPS 域名
  ├─ /             PWA 静态资源
  └─ /api/*        函数计算 API
                       └─ 私有 OSS monthly-data.json
```

## 推荐资源

1. 函数计算 FC 3.0，一个 Node.js 函数。
2. 一个私有 OSS Bucket，开启版本控制和服务端加密。
3. 一个 RAM 角色，只允许该函数读写指定 Bucket 中的指定对象前缀。
4. 一个已备案的自定义域名和 HTTPS 证书（中国内地节点时需要考虑备案）。
5. 两个独立凭证：管理凭证可读写，只读凭证只能读取。

## 安全规则

- AccessKey 只存在阿里云服务端配置中，不进入浏览器。
- 使用函数绑定的 RAM 角色，不使用主账号 AccessKey。
- 管理密码和只读密码保存为强哈希，不保存明文。
- 登录成功后签发短期会话，不把长期凭证放进 URL。
- API 对写请求校验管理角色，对读请求允许管理或只读角色。
- 限制请求大小，钱迹 CSV 原始内容解析后立即丢弃。
- 日志不得记录密码、会话令牌、CSV 正文或完整财务数据。

## 数据对象

云端只需要一个很小的数据对象：

```text
household/monthly-data.json
```

对象内容包括：

- `schemaVersion`
- `settings`，其中包含两人的工作档案
- `snapshots`
- `metadata.createdAt`
- `metadata.updatedAt`

启用 OSS 版本控制后，每次写入都会保留旧版本，效果类似财务数据的轻量提交历史，但不会把数据放进 Git。

## 需要用户在部署时完成的控制台操作

1. 确认部署地域和域名。
2. 创建私有 Bucket 并开启版本控制。
3. 创建函数计算应用并绑定 RAM 角色。
4. 在函数环境变量中设置管理/只读凭证哈希和会话签名密钥。
5. 配置自定义域名、HTTPS 和路由。

完成本地 V1 验收前，不需要做以上操作。

接口与环境变量约定见 `API_CONTRACT.md`。
